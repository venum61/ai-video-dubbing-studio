Локальный сервис для автоматического перевода и переозвучки видеороликов. Проект решает типичные проблемы простого дубляжа: сохраняет фоновые звуки (выстрелы, шаги, музыку), подгоняет темп речи под исходный хронометраж и не дает переводу звучать поверх оригинального голоса.

Есть веб-интерфейс с возможностью загрузки файлов или прямой записи с веб-камеры и микрофона.


## Как устроен пайплайн обработки

Весь процесс разбит на последовательные этапы:

1. **Нормализация и извлечение звука:** Видео (включая потоковый WebM из браузера) приводится к стандарту через FFmpeg, после чего извлекается аудиодорожка (WAV 16 kHz).
2. **Фильтрация тишины (VAD):** Собственная 1D-сверточная нейросеть на PyTorch сканирует сигнал окнами по 0.5 сек. Если в видео нет речи, пайплайн завершается до вызова тяжелых моделей.
3. **Распознавание речи:** OpenAI Whisper (`base`) с пословными таймкодами (`word_timestamps=True`). Это позволяет брать точное время начала первой реплики, а не приблизительную границу 30-секундного блока. Встроена фильтрация текстовых галлюцинаций и зацикливаний на фоновом шуме.
4. **Определение пола и тембра:** Метод автокорреляции вычисляет среднюю частоту основного тона ($F_0$ Pitch) оригинального голоса, разделяя мужской и женский тембр.
5. **Перевод:** Двунаправленный перевод (с/на русский, английский, испанский, немецкий, французский) с автоматическим переключением провайдеров (Google Translate / MyMemory).
6. **Синтез речи:** Озвучка через Microsoft Neural TTS (библиотека `edge-tts`) с автоматическим подбором диктора под определенный пол спикера.
7. **Сведение дорожек (Smart Ducking & Time-Stretching):** 
   - Во время реплики оригинальный звук приглушается до нуля через векторизованный фильтр NumPy, полностью убирая исходный голос;
   - В моменты пауз звуки окружения играют на 100% громкости;
   - Если переведенная фраза длиннее оригинала, применяется адаптивное ускорение темпа (`speedx` до 1.45x) без обрезания концовки.

## Архитектура проекта

```text
video_dubbing/
├── app/
│   ├── main.py                    # FastAPI приложение и эндпоинты
│   ├── models/
│   │   └── vad_model.py           # PyTorch архитектура 1D-CNN (VAD)
│   ├── services/
│   │   ├── audio_extractor.py     # Извлечение звука (MoviePy / FFmpeg)
│   │   ├── vad_service.py         # Инференс детектора речи
│   │   ├── voice_analyzer.py      # Анализ частоты F0 и пола спикера
│   │   ├── transcriber.py         # Whisper с пословными таймкодами
│   │   ├── translator.py          # Перевод с Fallback и адаптацией фраз
│   │   ├── synthesizer.py         # Нейросетевой синтез (Edge-TTS)
│   │   ├── video_builder.py       # Сведение звука, Ducking и рендеринг
│   │   └── pipeline.py            # Оркестратор полного цикла
│   └── templates/
│       └── index.html             # Веб-интерфейс с живым VU-метром
├── models/
│   └── vad_weights.pth            # Обученные веса VAD модели
├── tests/
│   ├── test_vad.py                # Тесты PyTorch модели
│   └── test_api.py                # Тесты FastAPI эндпоинтов
├── docker-compose.yml
├── Dockerfile
└── requirements.txt


Запуск проекта
1. Быстрый запуск через Docker (рекомендуется)
Требуется установленный Docker и Docker Compose:
docker compose up --build

Сервер поднимется на порту 8000. Веб-интерфейс доступен по адресу:
http://localhost:8000

Документация API (Swagger):
http://localhost:8000/docs

2. Локальный запуск без Docker
Требуется Python 3.10 и установленный в системе FFmpeg.
Клонировать репозиторий и настроить окружение:
git clone https://github.com/venum61/ai-video-dubbing-studio.git
cd ai-video-dubbing-studio
python -m venv venv

# Windows:
venv\Scripts\activate
# Linux / macOS:
source venv/bin/activate

Установить зависимости:
pip install -r requirements.txt

Запустить сервер:
uvicorn app.main:app --reload

Тестирование
Запуск тестов через pytest:
python -m pytest -v

Тесты проверяют:
Корректность размерностей тензоров и градиентов собственной 1D-CNN модели;
Работу адаптивного пулинга на произвольной длине аудиофайлов;
Доступность эндпоинта проверки работоспособности (/health);
Валидацию недопустимых форматов файлов и обработку несуществующих путей (400, 404).

Технологический стек
Бэкенд: Python 3.10, FastAPI, Uvicorn
ML / Аудио: PyTorch (собственная 1D-CNN), OpenAI Whisper, Edge-TTS
Обработка медиа: FFmpeg, MoviePy, NumPy
Фронтенд: HTML5, CSS (Glassmorphism), Vanilla JS (Web Audio API для VU-метра и MediaRecorder)
Инфраструктура: Docker, Docker Compose, Pytest
